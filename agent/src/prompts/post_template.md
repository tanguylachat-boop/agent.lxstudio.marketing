# Post Generation Template

## Contexte
- **Marque** : LX Studio (agence web/IA premium, Suisse)
- **Niche** : {{NICHE}}
- **Tendances actuelles** : {{TRENDS}}
- **Persona cible** : {{PERSONA}}
- **Objectif** : Générer des leads qualifiés (DM "AGENT" ou "SITE")

## Instructions de Génération
Crée un script vidéo viral de 20-35 secondes qui :
1. Capte l'attention dans les 3 premières secondes
2. Présente un problème/opportunité relatable pour {{PERSONA}}
3. Positionne LX Studio comme la solution évidente
4. Termine par un CTA clair et actionnable

## Contraintes
- Durée de narration : 20-35 secondes exactement
- Langue : Français (Suisse/France)
- Ton : Professionnel, premium, confiant
- Format : JSON strict

## Éléments à Intégrer
- **Tendances** : Référence subtile aux trends TikTok/IG actuels si pertinent
- **Crédibilité** : Mention de résultats, expertise, ou différenciation
- **Urgence** : Sentiment de FOMO ou opportunité limitée (sans être agressif)

## Variantes de Hooks
Propose 2 variantes de hook (HOOK_A et HOOK_B) pour test A/B :
- HOOK_A : Approche problème/douleur
- HOOK_B : Approche résultat/transformation

## Hashtags Stratégiques
Inclure 5-8 hashtags mixant :
- Niche spécifique (#AI, #SEO, #Automation)
- Géo (#Suisse, #Geneve, #Lausanne si pertinent)
- Viralité (#FYP, #TikTokGrowth, #BusinessTips)
- Branding (#LXStudio)

## Output Attendu
```json
{
  "HOOK_A": "80% des PME perdent des clients chaque jour sans le savoir.",
  "HOOK_B": "On a multiplié par 3 les leads d'un client en 60 jours. Voici comment.",
  "SCRIPT": "[Script complet ici, formaté pour narration naturelle]",
  "CTA": "DM 'AGENT' pour un audit gratuit de ton automatisation",
  "HASHTAGS": ["#automation", "#ai", "#business", "#suisse", "#fyp", "#entrepreneur"],
  "DESCRIPTION": "LX Studio aide les PME à automatiser leur croissance avec l'IA. Audit gratuit en DM."
}
```

## Best Practices
- Utiliser des chiffres concrets quand possible
- Créer un gap émotionnel (où tu es vs. où tu pourrais être)
- Rester authentique (pas de promesses irréalistes)
- Adapter le vocabulaire au persona (B2B vs. B2C)
